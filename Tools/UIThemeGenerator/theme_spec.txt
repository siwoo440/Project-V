# UI 테마 시트 목록. process_theme.ps1이 읽는다.
# 요청문(GPT_Request_UI_01.md)의 시트 배치와 같은 순서로 적는다.
#
# sheet | 원본 파일 | 줄x칸 | 종류 | 저장 폴더(Art 기준) | 조각 이름(왼쪽 위부터)
#   종류: nine  = 네 변을 유지하고 가운데를 늘리는 패널
#         three = 좌우 끝을 유지하고 가운데를 늘리는 막대
#         card  = 2:3 카드 틀 (늘리지 않음)
#         icon  = 정사각형 아이콘. "이름=글자아이콘이름"으로 적으면 글자 사이에 넣을 수 있다.
#         emblem = 다듬기만 하는 그림
#         strip = 다듬기만 하는 긴 장식 (구분선)
#   조각 이름 뒤에 ":종류"를 붙이면 그 조각만 종류를 바꾼다.
# bg | 원본 파일 | 저장 폴더(Art 기준)
# border | 조각 이름 | 왼쪽,아래,오른쪽,위   (자동 계산한 경계를 직접 정할 때)
# nocompact | 조각 이름                       (가운데 구간을 줄이지 않을 때)
