\# Project V 37일차 개발일지



\---



\## 1. 작업 목표



33일차에 만든 덱 편성 화면은 보유 카드와 현재 덱을 표시하는 읽기 전용 상태였다. 카드 추가와 제거를 구현해 플레이어가 직접 덱을 구성할 수 있도록 한다. 편성 화면의 UI도 카드 형태로 다시 구성한다.



\---



\## 2. 구현 내용



\- 편성 중 카드 추가 검증 구현

\- 덱 비우기 기능 구현

\- 카드별 덱 편성 수량 조회 구현

\- 편성 실패 사유 표시 구현

\- 계열 분포 표시 구현

\- 희귀도 분포 표시 구현

\- 빈 덱 전투 검증 반영

\- 덱 편성 화면 레이아웃 재구성

\- 편성 조작 버튼 추가



\---



\## 3. 편성 검증



기존 덱 검증은 완성된 30장을 검사하는 방식이라 편성 중간 상태에 사용할 수 없었다. 카드 1장을 추가할 수 있는지 판정하는 검증을 추가했다.



검사 항목은 다음과 같다.



\- 덱 장수 초과

\- 희귀도별 중복 제한 초과

\- 보유 수량 초과

\- 전설 마물 3장 초과

\- 보스 출신 마물 1장 초과

\- 토큰 마물 편성

\- 마물 데이터가 없는 카드



제한 수치는 희귀도 규칙에서 가져오므로 전투 시작 검증과 편성 검증이 같은 기준을 사용한다.



\---



\## 4. 편성 조작



| 조작 | 결과 |

| --- | --- |

| 보유 카드 클릭 | 덱에 1장 추가 |

| 덱 카드 클릭 | 덱에서 1장 제거 |

| 덱 비우기 | 덱 전체 제거 |

| 보유 카드로 채우기 | 보유 수량만큼 덱 재구성 |



추가할 수 없는 카드는 흐리게 표시하고 클릭을 막는다. 추가를 시도해 실패하면 사유를 화면에 표시한다.



기획서 6.12.6에 따라 자동 편성은 제공하지 않는다. 덱 비우기와 채우기는 테스트 편의를 위한 기능이다.



\---



\## 5. 덱 통계



| 통계 | 표시 |

| --- | --- |

| 카드 수 | 현재 장수와 필요 장수 |

| 평균 마나 | 편성 카드의 평균 비용 |

| 계열 분포 | 계열별 카드 수 |

| 희귀도 분포 | 희귀도별 카드 수 |



계열 분포에는 시너지가 필드 기준이라는 안내를 함께 표시한다. 덱에 고블린이 많아도 필드에 소환해야 시너지가 활성화되기 때문이다.



\---



\## 6. 화면 구성



| 영역 | 배치 |

| --- | --- |

| 상단 | 화면 제목, 덱 장수와 평균 마나 |

| 좌측 | 보유 카드 목록 |

| 우측 | 현재 덱 목록 |

| 좌측 하단 | 계열과 희귀도 분포, 안내 문구 |

| 우측 하단 | 보유 카드로 채우기, 덱 비우기, 돌아가기 |



두 목록에 스크롤 영역과 잘림 처리를 적용해 항목이 패널 밖으로 넘치지 않는다. 29일차에 만들어진 빈 껍데기 패널이 배경을 덮고 있어 비활성 처리했다.



\---



\## 7. 카드 항목 디자인



목록 항목을 가로 줄에서 세로형 카드로 변경했다.



\- 카드 크기 190 × 230, 가로 4열 배치

\- 상단에 희귀도 색 띠

\- 좌상단에 마나 비용 배지

\- 중앙에 카드 이름

\- 계열 이름은 타입 색상으로 표시

\- 희귀도 이름은 희귀도 색상으로 표시

\- 하단에 수량 영역 배치

\- 보유 목록은 덱 수와 보유 수, 덱 목록은 편성 수량 표시

\- 편성할 수 없는 카드는 전체를 어둡게 처리



\---



\## 8. 빈 덱 처리



덱이 비어 있으면 씬에 저장된 덱으로 되돌아가던 동작을 제거했다. 덱을 비운 상태 그대로 전투에 전달해 덱 검증이 사유를 표시하도록 했다.

\## 10. 작업 결과



플레이어가 보유 카드를 직접 편성할 수 있게 되어 31일차의 보유 한도, 32일차의 편성 제한, 35일차의 고유 효과, 36일차의 타입 시너지가 모두 덱 구성으로 연결된다.
