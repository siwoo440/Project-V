\# Project V 34일차 개발일지



\---



\## 1. 작업 목표



33일차에 구성한 전투 화면에서 패널이 서로 겹치고 손패 카드가 포개지는 문제가 남아 있었다. 전투 화면의 영역 배치를 다시 잡고, 전투 중 항상 표시될 필요가 없는 패널을 기본 비활성 상태로 정리한다.



\---



\## 2. 구현 내용



\- 전투 로그 패널 기본 비활성 처리

\- 마물 도감 패널 기본 비활성 처리

\- 전투 결과 패널 기본 비활성 처리

\- 상태 효과 툴팁 기본 비활성 처리

\- 손패 카드 프리팹 크기 조정

\- 손패 카드 간격 조정

\- 손패 카드 텍스트 여백 적용

\- 카드 프리팹 정리 에디터 기능 추가

\- 우측 정보 열 영역 분리

\- 좌하단 보조 버튼 세로 배치

\- 마물 필드 영역 조정

\- 덱 상태와 손패 안내 위치 분리

\- 닫기 버튼 문구 통일



\---



\## 3. 문제 원인



| 증상 | 원인 |

| --- | --- |

| 화면 중앙에 회색 상자와 진행 정보가 표시됨 | 마물 도감 패널이 켜진 상태로 씬에 저장됨 |

| 좌측 정보가 가려짐 | 전투 로그 패널이 켜진 상태로 씬에 저장됨 |

| 손패 카드가 서로 포개짐 | 카드 10장을 넣기 위해 간격을 음수로 지정함 |

| 좌하단 버튼과 손패가 겹침 | 손패 영역이 화면 대부분을 차지함 |

| 행동 예고와 히로인 정보가 겹침 | 두 패널의 세로 영역이 중첩됨 |



\---



\## 4. 손패 배치



| 항목 | 기존 | 변경 |

| --- | --- | --- |

| 카드 크기 | 210 × 160 | 140 × 200 |

| 카드 간격 | \-40 | 10 |

| 손패 영역 | 1860 | 1500 |

| 카드 텍스트 | 여백 없음 | 안쪽 여백 8 |



최대 손패 10장 기준 140 × 10 + 10 × 9 = 1490으로 손패 영역 1500 안에 들어간다. 5장일 때는 740으로 가운데에 모인다.



\---



\## 5. 화면 영역



| 영역 | 배치 | 세로 범위 |

| --- | --- | --- |

| 좌상단 | 플레이어 정보 | 920 \~ 1080 |

| 상단 중앙 | 턴 정보 | 960 \~ 1060 |

| 우상단 | 히로인 정보 | 740 \~ 1060 |

| 우측 | 행동 예고 | 585 \~ 735 |

| 우측 | HP 공격, 성욕 공격, 턴 종료 | 315 \~ 545 |

| 중앙 | 마물 필드 8체 | 530 \~ 830 |

| 하단 | 전투 안내 | 308 \~ 352 |

| 하단 | 손패 | 50 \~ 250 |

| 좌측 하단 | 전투 로그, 도감 | 118 \~ 240 |



마물 필드는 가로 1200으로 조정해 우측 정보 열과 겹치지 않게 했다. 좌하단 보조 버튼은 세로로 쌓아 손패 영역과 분리했다.



\---



\## 6. 기본 비활성 패널



전투 시작 시 다음 패널을 꺼진 상태로 유지한다.



\- 전투 로그 패널

\- 마물 도감 패널

\- 전투 결과 패널

\- 상태 효과 툴팁



각 패널은 열기 버튼과 기존 스크립트에서 활성화하므로 동작에는 영향이 없다. 상태 효과 툴팁은 표시 시점에 스스로 활성화한다.



\---



\## 7. 테스트 내용



\- 전투 시작 시 패널 표시 없음

\- 전투 로그 열기와 닫기

\- 마물 도감 열기와 닫기

\- 상태 효과 툴팁 표시

\- 전투 결과 패널 표시

\- 손패 5장 배치

\- 손패 10장 배치

\- 마물 8체 필드 배치

\- 좌하단 버튼과 손패 겹침 확인

\- 우측 패널 겹침 확인

\- Unity Console 오류 확인



\---



\## 8. 작업 결과



전투 시작 화면에서 정보 패널과 마물 필드, 손패만 표시된다. 전투 로그와 도감은 좌측 버튼으로 직접 열었을 때만 나타난다. 손패 카드는 최대 10장까지 겹치지 않고 배치된다.



UI 배치 수치는 씬 UI 도구의 전투 화면 구성 함수에 모여 있어 값을 바꾸고 메뉴를 다시 실행하면 반영된다.



\---



\## 9. 다음 개발 방향



35일차에는 마물 고유 효과 시스템을 구현한다. 소환, 지속, 능동 스킬, 사망 4종의 발동 시점과 재사용 대기시간을 처리하고 시작 덱 11종의 고유 효과를 적용한다.
