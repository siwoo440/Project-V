\# Project V 38일차 개발일지



\---



\## 1. 작업 목표



37일차에 덱 편성을 구현했지만 덱을 하나만 사용할 수 있었고, 보유 카드가 늘어나면 원하는 카드를 찾기 어려웠다. 기획서 6.12.3의 덱 프리셋과 6.12.4의 필터, 6.12.5의 정렬을 구현한다.



\---



\## 2. 구현 내용



\- 덱 프리셋 데이터 추가

\- 카드 정렬 방식 열거형 추가

\- 덱 보관 구조를 프리셋 5개로 교체

\- 프리셋 선택 구현

\- 프리셋 이름 변경 구현

\- 프리셋 구성 복사 구현

\- 계열 필터 구현

\- 희귀도 필터 구현

\- 마나 비용 필터 구현

\- 이름 검색 구현

\- 정렬 5종 구현

\- 프리셋 선택 버튼 생성

\- 필터와 정렬 버튼 생성

\- 입력 필드 생성 기능 추가

\- 선택 프리셋 강조 표시



\---



\## 3. 덱 프리셋



| 기능 | 처리 |

| --- | --- |

| 프리셋 수 | 5개 고정 |

| 프리셋 선택 | 선택한 프리셋이 전투에 사용됨 |

| 이름 변경 | 입력 필드로 직접 수정 |

| 덱 복사 | 직전에 선택했던 프리셋 구성을 복사 |

| 덱 초기화 | 선택한 프리셋만 비움 |



현재 덱 조회를 선택한 프리셋을 가리키는 속성으로 변경했다. 전투 덱 적용과 지역 선택 화면, 편성 기능은 수정하지 않아도 선택한 프리셋을 따라간다.



덱 복사는 카드 목록을 값으로 복사한다. 복사한 뒤 원본을 수정해도 복사본은 영향을 받지 않는다.



\---



\## 4. 필터



| 필터 | 항목 |

| --- | --- |

| 계열 | 전체와 타입 9종 |

| 희귀도 | 전체와 희귀도 4종 |

| 마나 비용 | 전체, 0\~2, 3\~5, 6 이상 |

| 이름 검색 | 입력한 문자열 포함 |



기획서 6.12.4에서 제외한 전투 역할과 획득 순서, 즐겨찾기 필터는 구현하지 않았다. 강화 단계 필터는 마물 강화 구현 이후에 추가한다.



필터는 보유 카드 표시에만 적용하며 덱 데이터는 변경하지 않는다. 필터가 걸린 상태에서도 편성과 검증은 전체 덱을 기준으로 동작한다.



\---



\## 5. 정렬



기획서 6.12.5 기준으로 5종을 구현했다.



\- 이름순

\- 마나 낮은 순

\- 마나 높은 순

\- 희귀도순

\- 계열순



강화 레벨순은 마물 강화 구현 이후에 추가한다.



\---



\## 6. 조작 방식



필터와 정렬은 누를 때마다 항목이 순환하는 버튼으로 구현했다. 드롭다운은 템플릿 계층을 함께 만들어야 하는데 현재 항목 수에서는 순환 버튼이 조작 횟수와 구조 모두 단순하다.



\- 계열, 희귀도, 마나, 정렬 버튼은 현재 선택값을 라벨에 표시

\- 프리셋 버튼은 프리셋 이름을 라벨에 표시

\- 선택한 프리셋은 강조 색으로 구분

\- 덱 복사 버튼은 복사 대상 프리셋 이름을 표시

\## 7. 화면 구성



| 영역 | 배치 |

| --- | --- |

| 상단 | 화면 제목, 프리셋 이름과 덱 통계 |

| 첫째 줄 | 프리셋 버튼 5개, 이름 입력, 덱 복사 |

| 둘째 줄 | 계열, 희귀도, 마나 필터, 이름 검색, 정렬 |

| 좌측 | 보유 카드 목록 |

| 우측 | 현재 덱 목록 |

| 좌측 하단 | 계열과 희귀도 분포, 안내 문구 |

| 우측 하단 | 보유 카드로 채우기, 덱 비우기, 돌아가기 |



조작 줄을 추가하면서 목록 패널 높이를 720에서 620으로 조정했다.

\## 9. 작업 결과



덱을 5개까지 저장하고 전환할 수 있게 되어 콘텐츠별로 다른 구성을 준비할 수 있다. 필터와 정렬을 적용해 보유 카드가 늘어나도 원하는 카드를 찾을 수 있다.



프리셋은 저장 대상이므로 직렬화 가능한 구조로 만들었다. 게임을 종료하면 초기화되며 저장은 저장 및 불러오기 일차에서 처리한다.



\---



\## 10. 다음 개발 방향



39일차에는 마물 카드 강화를 구현한다. 기획서 6.9의 강화 단계 Lv.1부터 Lv.5까지와 9.11의 정수 및 골드 비용을 적용하고, 카드 복사본별 개별 강화를 처리한다.
