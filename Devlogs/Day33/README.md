\# Project V 33일차 개발일지



\---



\## 1. 작업 목표



지금까지 각 씬이 개별적으로만 동작하고 서로 연결되어 있지 않았다. 씬 전환 구조를 만들어 게임 흐름을 연결하고, 각 씬의 UI를 기획서 기준으로 배치한다. 화면에 표시되는 모든 문구를 한글로 변경한다.



\---



\## 2. 구현 내용



\- 씬 이름 상수 정의

\- 씬 전환 관리 기능 구현

\- 이전 씬 복귀 처리 구현

\- 이름 기반 UI 자동 연결 구현

\- 진입 씬 자동 로드 구현

\- 메인 메뉴 화면 연결

\- 스토리 화면 연결

\- 전투 씬 복귀 버튼 구현

\- 진행 데이터에 현재 덱 추가

\- 전투에서 플레이어 덱 사용 구현

\- 전체 문구 한글 번역



\---



\## 3. 씬 흐름



| 씬 | 이동 대상 |

| --- | --- |

| 00\_Bootstrap | 진행 데이터 생성 후 메인 메뉴 |

| 01\_MainMenu | 스토리 / 지역 선택 / 덱 편성 / 게임 종료 |

| 02\_DeckBuilder | 직전 씬으로 복귀 |

| 03\_StageSelect | 전투 / 덱 편성 / 메인 메뉴 |

| 04\_Story | 대사 종료 후 지역 선택 |

| BattleScene | 지역 선택으로 복귀 |



진입점은 00\_Bootstrap이다. 진행 데이터 관리자를 이 씬에서 생성하고 씬 전환 사이에도 유지한다. BattleScene에도 진행 데이터 관리자를 남겨 단독 실행 테스트를 유지하며, 진입 씬을 거치면 싱글턴 규칙에 따라 전투 씬의 사본이 제거된다.



\---



\## 4. 덱 연동



덱이 전투 씬에 고정되어 있으면 화면 연결이 의미가 없으므로 덱 데이터를 진행 데이터로 옮겼다.



\- 시작 보유 카드로 전투 덱 자동 구성

\- 전투 시작 시 진행 데이터의 덱 사용

\- 진행 데이터가 없으면 기존 씬 덱 사용

\- 덱 교체는 31일차 보유 검증을 통과해야 적용



덱 편성 화면은 보유 카드와 현재 덱을 표시하는 읽기 전용 상태다. 카드 추가와 제거는 덱 편성 일차에 구현한다.



\---



\## 5. UI 배치 규칙



기획서 11.2와 11.4.1을 기준으로 정리했다.



\- 기준 해상도 1920×1080, 16:9 안전 영역 유지

\- 기본 배경 검정, 주요 패널 짙은 보라

\- 선택과 강조는 금색, 일반 텍스트는 밝은 회색

\- 종료 버튼은 경고색 사용

\- 희귀도 색상은 일반 회색, 희귀 파란색, 특수 보라색, 전설 금색

\- 타입 색상 9종 정의



씬 UI는 에디터 도구로 생성한다. 씬 파일을 직접 수정하면 직렬화가 깨질 위험이 있어 Unity가 직접 구성하도록 했다.

\## 6. 전투 화면 재배치



전투 화면의 UI가 서로 겹치고 카드 밖으로 글자가 넘치는 문제를 해결했다.



| 영역 | 배치 |

| --- | --- |

| 좌상단 | 플레이어 HP, 보호막, 마나 |

| 상단 중앙 | 턴 상태와 턴 번호 |

| 우상단 | 히로인 HP, 방어, 보호막, 성욕, 상태 효과 |

| 우측 | 행동 예고, HP 공격, 성욕 공격, 턴 종료 |

| 중앙 | 마물 필드 8체 |

| 하단 | 손패, 덱 수량, 전투 안내 |

| 좌하단 | 전투 로그, 도감, 지역 선택 |



손패 레이아웃에 안내 텍스트와 빈 컨테이너가 자식으로 들어 있어 카드처럼 배치되던 문제를 분리해 해결했다. 결과 패널과 도감 패널은 항상 최상단에 표시되도록 순서를 정리했다.



마물 카드 프리팹은 130×190 크기에 200×50 텍스트 7개가 배치되어 있었다. 카드를 130×220으로 조정하고 세로 레이아웃과 고정 행 높이를 적용했다.

\## 7. 한글화



\- 전투 UI 및 전투 로그 문구

\- 전투 결과 및 포획 결과 문구

\- 덱 검증 오류 문구

\- 마물 유닛 능력치 표기

\- 상태 효과 툴팁

\- 희귀도와 타입 이름

\- 씬 흐름 화면의 모든 버튼과 안내

\- 마물 17종, 카드 17종, 상태 효과 7종, 히로인 행동 12종

\- 인스펙터 헤더와 콘솔 문구

\- 에디터 메뉴와 에셋 생성 메뉴



오브젝트 이름과 카드 및 마물 ID는 번역하지 않았다. 이름 기반 UI 연결과 보유 수량 관리에 사용하는 값이기 때문이다.



프로젝트에 한글 글리프를 가진 글꼴이 없어 번역만으로는 글자가 표시되지 않았다. 시스템 한글 글꼴로 동적 글꼴 에셋을 만들어 TMP 전역 대체 글꼴로 등록하는 도구를 추가했다. 배포용으로는 라이선스가 자유로운 한글 글꼴을 프로젝트에 포함해 교체해야 한다.

\## 8. 문제 해결



\- 진입 씬의 입력 모듈이 레거시 방식이어서 Input System 설정과 충돌했다. 입력 모듈을 교체하고, 에디터 도구가 프로젝트 입력 설정에 맞는 모듈을 적용하도록 수정했다.

\- 손패 레이아웃에 카드가 아닌 오브젝트가 포함되어 있었다. 안내 텍스트와 덱 수량 텍스트를 캔버스 직속으로 분리했다.

\- 씬에 직렬화된 스토리 대사와 스테이지 데이터가 영문으로 남아 있었다. 에디터 도구의 기본값은 목록이 비어 있을 때만 채우므로 씬 데이터를 직접 수정했다.

\## 10. 작업 결과



각 씬이 하나의 흐름으로 연결되어 진입 씬에서 시작해 전투까지 진행하고 다시 지역 선택으로 돌아올 수 있다. 전투 덱이 진행 데이터에서 관리되므로 이후 덱 편성 기능을 붙일 준비가 끝났다.



전투 화면의 UI 겹침과 글자 넘침을 정리했고, 화면에 표시되는 모든 문구를 한글로 변경했다.
