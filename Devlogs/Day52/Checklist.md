# 지역 1 점검 순서표 (52일차)

새 게임부터 지역 2 해금까지를 순서대로 확인한다. 단계마다 오른쪽의 내용이 보이면 정상이다.
전투 화면 오른쪽의 시험 버튼(승리, 성욕, 패배, 마나)은 에디터에서만 보인다. 긴 전투를 끝까지 하지 않고 다음 단계로 넘어갈 때 쓴다.

문제가 보이면 다음 세 가지를 알려 주면 된다.

- 몇 번 단계에서 무엇을 눌렀는지
- 화면 캡처 (겹치거나 넘치는 글자가 있으면 그 부분)
- Unity Console의 빨간 글 첫 줄

## A. 준비

| 번호 | 할 일 | 정상일 때 |
| --- | --- | --- |
| A1 | Unity에서 컴파일이 끝난 뒤 `Project V > 씬 UI 다시 구성` 실행 | Console에 `씬 UI를 구성했습니다` 13줄 |
| A2 | `00_Bootstrap` 씬을 열고 실행 | 메인 메뉴가 열림 |

## B. 새 게임에서 전투 준비까지

| 번호 | 할 일 | 정상일 때 |
| --- | --- | --- |
| B1 | 메인 메뉴에서 새 게임을 두 번 눌러 시작 | 월드맵으로 이동 |
| B2 | 지역 1을 골라 지역 진입 | 도입 스토리가 먼저 나옴. 다음으로 넘기거나 건너뛰면 지역 화면으로 옴 (53일차부터) |
| B2-1 | 지역 화면 확인 | 메인 진행 탭에 아리아 1차전만 열려 있고, 일반전과 2·3차전은 잠금 조건이 적혀 있음 |
| B3 | 서브 콘텐츠 탭 누르기 | 실리아, 리엔, 프라나야, 포획전 1~3이 잠긴 채 보임 |
| B4 | 메인 진행 탭에서 아리아 1차전 고르기 | 상세 칸에 아리아 얼굴 그림과 닫힌 상자 그림 |
| B5 | 전투 준비 누르기 | 준비 화면. 왼쪽에 아리아 그림, HP 220 / 공격 8 / 방어 4, 행동 2개 |
| B6 | 난이도 쉬움 누르기 | HP 176, 공격 6. 보상이 골드 160, 경험치 64, 파편 2로 바뀜 |
| B7 | 난이도 보통으로 되돌리기 | 보상이 골드 200, 경험치 80, 파편 3 |
| B8 | 프리셋 화살표, 액티브 스킬, 소모품 버튼 누르기 | 누를 때마다 내용이 바뀌거나 바꿀 것이 없다는 안내가 나옴 |
| B9 | 덱 편성에 들어갔다가 돌아가기 | 전투 준비 화면으로 돌아옴 |

## C. 전투

| 번호 | 할 일 | 정상일 때 |
| --- | --- | --- |
| C1 | 전투 시작 누르기 | 손패 5장과 손패 교환 창이 보임. 위쪽 가운데에 아리아 그림, 턴 표시는 왼쪽 |
| C2 | 손패 2장을 눌러 고르고 교환 | 고른 카드가 흐려졌다가 새 카드 2장으로 바뀜. 손패 5장 유지 |
| C3 | 카드를 소환하고 턴 종료 | 아리아가 행동하고 다음 내 턴이 시작됨 |
| C4 | 마물로 HP 공격 | 아리아 그림이 피격 그림으로 잠깐 바뀜 |
| C5 | 마물로 성욕 공격 | 홍조 그림으로 잠깐 바뀌고 성욕 게이지가 오름 |
| C6 | 오른쪽 위의 속도 버튼 누르기 | x1.5, x2로 바뀌고 아리아의 행동이 빨라짐 |
| C7 | 여러 턴 진행 | 전투 로그에 가끔 치명타와 회피가 나옴 |
| C8 | 시험 버튼 성욕 누르기 | 성욕 100 / 100 절정. 전투가 바로 끝나지 않음 |
| C9 | 턴 종료 | 아리아가 행동한 뒤 내 턴이 시작되면서 승리 - 성욕 최대 |

## D. 승리 뒤의 진행

| 번호 | 할 일 | 정상일 때 |
| --- | --- | --- |
| D1 | 결과 창 확인 뒤 계속, 왼쪽 아래의 지역 버튼 | 골드 +200, 경험치 +80, 파편 +3. 지역 화면으로 돌아옴 |
| D2 | 지역 화면 확인 | 아리아 1차전 줄에 왕관. 일반전 1단계가 열림 |
| D3 | 일반전 1단계 → 전투 준비 → 전투 시작 | 위쪽에 적 마물 2체. 히로인 그림과 성욕 공격 버튼은 없음 |
| D4 | 손패 교환을 마치고 시험 버튼 승리 | 승리 - 적 전멸. 골드 +100, 경험치 +40, 정수 +5 |
| D5 | 일반전 2단계, 3단계를 같은 방법으로 | 차례로 열리고, 3단계 뒤에 아리아 2차전이 열림 |
| D6 | 아리아 2차전의 전투 준비 화면 | 행동 4개, 행동 횟수가 매 턴 1회, 3턴마다 2회 |
| D7 | 2차전에서 시험 버튼 승리 | 승리 - HP 소진. 골드 +300, 경험치 +120, 파편 +5 |
| D8 | 지역 화면의 서브 콘텐츠 탭 | 서브 히로인전 3개와 포획전 3개가 열림. 메인 진행 탭에는 3차전이 열림 |
| D9 | 포획전 하나를 이기기 | 결과 창에 포획한 마물 이름. 덱 편성 화면에 그 카드가 생김 |
| D10 | 포획전 줄을 고르고 목록 다시 뽑기 | 골드가 200 줄고 세 줄의 마물이 바뀜 |
| D11 | 아리아 3차전에서 시험 버튼 승리 | 결과 창에 골드 +500, 경험치 +200, 파편 +7 |
| D11-1 | 계속을 누르고 지역 버튼으로 나가기 | 마무리 스토리가 나옴. 끝나면 월드맵으로 감 (53일차부터) |
| D12 | 월드맵 확인 | 안내 줄에 지역 클리어와 보상(골드 +500, 파편 +30), 새 지역 해금. 지역 1이 클리어로 표시되고 지역 2가 열림 |

## E. 패배, 포기, 재도전

| 번호 | 할 일 | 정상일 때 |

## F. 저장

| --- | --- | --- |

## G. 시험 버튼 없이 한 판

아리아 1차전을 시험 버튼 없이 끝까지 한 번 해 본다. 아래를 알려 주면 수치를 맞춘다.

- 몇 턴에 끝났는지, HP와 성욕 중 무엇으로 이겼는지
- 마물이 너무 쉽게 죽거나 전혀 죽지 않는지
- 지루하게 길거나 할 일이 없는 턴이 있었는지
