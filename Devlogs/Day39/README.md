\# Project V 39일차 개발일지



\---



\## 1. 작업 목표



38일차까지 마물 카드는 포획한 순간의 성능이 전부였다. 중복 포획으로 얻은 마물의 정수는 쌓이기만 하고 사용처가 없었다. 기획서 6.9의 마물 카드 강화를 구현해 정수와 골드의 사용처를 만들고, 6.9.1의 "마물 카드는 한 장마다 개별적으로 강화" 규칙을 따라 카드 보유 구조를 사본 단위로 전환한다.



추가 작업으로 강화 화면을 덱 편성에서 분리해 05\_Enhance 씬으로 옮긴다.

\## 3. 카드 사본 구조



기획서 6.9.1에 따라 같은 카드라도 사본마다 강화 단계가 다르다. 보유 수량만 세던 구조로는 표현할 수 없어 보관 방식을 바꾸었다.



| 구분 | 38일차까지 | 39일차 |

| --- | --- | --- |

| 보유 카드 | 카드 + 보유 수량 | 카드 + 사본 목록 |

| 사본 | 없음 | 사본 번호 + 강화 단계 |

| 덱 프리셋 | 카드 목록 | 사본 목록 |

| 전투 덱 | 카드 목록 | 사본 목록 |



사본은 고유하므로 같은 사본을 덱에 두 번 넣을 수 없다. 희귀도별 보유 한도와 편성 제한은 사본의 카드 ID를 세어 그대로 유지한다.



\---



\## 4. 강화 규칙



기획서 6.9.2의 최대 단계와 9.11의 정수 및 골드 비용을 적용했다. 6.9.3은 공용 강화 재료를 사용한다고 적혀 있어 9.11과 충돌하므로 9.11을 기준으로 삼았다.



| 희귀도 | 기본 정수 | 기본 골드 |

| --- | --- | --- |

| 일반 | 2 | 100 |

| 희귀 | 4 | 200 |

| 특수 | 6 | 350 |

| 전설 | 10 | 600 |



| 단계 | 비용 배수 |

| --- | --- |

| Lv.1 → Lv.2 | 1배 |

| Lv.2 → Lv.3 | 2배 |

| Lv.3 → Lv.4 | 3배 |

| Lv.4 → Lv.5 | 5배 |



일반 카드를 Lv.5까지 올리면 정수 22개와 골드 1,100이 필요하다.



능력치는 마물 데이터의 단계별 성장 수치를 사용한다. 강화 단계가 1 오를 때마다 체력, 공격, 방어, 성욕 성장치가 한 번씩 더해진다.



\---



\## 5. 강화 불가 조건



기획서 6.9.6의 조건을 판정하고 사유를 화면에 표시한다.



| 조건 | 안내 |

| --- | --- |

| 보유하지 않은 사본 | 보유하지 않은 사본입니다 |

| 최대 단계 도달 | 이미 최대 단계입니다 |

| 강화 상한 초과 | 현재 강화 상한을 표시 |

| 정수 부족 | 보유량과 필요량을 표시 |

| 골드 부족 | 보유량과 필요량을 표시 |



기획서 6.9.7에 따라 강화는 되돌릴 수 없다. 실수를 막기 위해 강화 버튼을 한 번 누르면 확인 안내가 나오고, 한 번 더 눌러야 실행된다.



강화 상한은 기획서 6.9.6의 플레이어 레벨 제한을 위한 자리이다. 플레이어 레벨은 40일차에 구현하므로 지금은 진행 데이터의 설정 값으로 둔다.

\## 6. 성장 수단 정리



28일차에 넣은 보유 마물 경험치 성장을 제거했다. 기획서 6.9의 성장 수단은 강화 하나뿐이며, 경험치 레벨업과 강화 단계가 같은 능력치를 두 번 올리는 문제가 있었다.



마물 도감의 레벨 표시는 해당 마물 카드의 보유 사본 중 최고 강화 단계를 따른다.



\---



\## 7. 전투 반영



덱에서 뽑은 사본이 손패와 소환까지 그대로 이어진다.



| 위치 | 표시 |

| --- | --- |

| 손패 카드 | 카드 이름과 Lv.단계 |

| 전투 기록 | 사용한 사본의 단계 |

| 필드 마물 | 마물 이름과 Lv.단계 |



마물 능력치는 소환에 사용한 사본의 강화 단계로 계산한다. 마물 효과로 생성되는 토큰 마물은 사본이 없으므로 Lv.1로 소환된다.



씬에 직접 넣은 덱을 사용하는 경우에는 강화되지 않은 임시 사본으로 다룬다.

\## 8. 마물 강화 화면



강화를 덱 편성 화면에 붙였다가 05\_Enhance 씬으로 분리했다. 왼쪽은 덱 편성과 같은 보유 카드 목록이고, 오른쪽 강화대에 카드를 올려 강화한다.



| 영역 | 구성 |

| --- | --- |

| 상단 | 제목, 덱 편성 이동, 보유 골드와 정수 |

| 필터 줄 | 계열, 희귀도, 마나, 이름 검색, 정렬 |

| 왼쪽 | 보유 카드 목록 가로 4장 배치 |

| 오른쪽 위 | 강화대에 올린 카드와 선택 사본의 단계 |

| 오른쪽 가운데 | 강화 전후 능력치와 필요 비용 |

| 오른쪽 아래 | 사본 목록, 강화, 내려놓기 |

| 하단 | 안내 문구, 돌아가기 |



보유 카드를 누르면 강화대에 올라간다. 사본 목록에서 강화할 사본을 고르면 능력치 비교와 비용이 갱신된다. 덱에 편성 중인 사본은 목록에 편성 중으로 표시한다.



덱 편성 화면과 메인 메뉴에 강화 화면으로 이동하는 버튼을 추가했다.

\## 13. 작업 결과



마물의 정수와 골드에 사용처가 생겼고, 같은 카드를 여러 장 모을 이유가 생겼다. 사본마다 강화 단계가 달라 덱을 짤 때 어느 개체를 넣을지 고르게 되었다.



강화를 별도 씬으로 분리해 덱 편성 화면은 편성에만 집중하고, 강화 화면은 카드 한 장을 크게 보여주며 강화에 집중한다.



강화 상태는 저장 대상이므로 직렬화 가능한 구조로 만들었다. 게임을 종료하면 초기화되며 저장은 저장 및 불러오기 일차에서 처리한다.



강화를 확인하려면 시작 자원이 필요해 진행 데이터의 시작 골드를 2000, 시작 정수를 40으로 설정했다. 정식 수치는 경제와 상점 일차에서 다시 정한다.



강화 단계 필터는 넣지 않았다. 필터 줄에 버튼을 더 늘리면 화면이 좁아지므로 화면 정식화 일차에서 함께 정리한다.
