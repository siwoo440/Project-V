\# Project V 45일차 개발일지



\---



\## 1. 작업 목표



44일차까지는 메인 메뉴에 스토리, 지역 선택, 덱 편성, 강화, 상점이 한 줄로 늘어서 있었고 지역은 하나뿐이었다. 기획서 4.3의 월드맵을 만들어 지역 선택과 성장 관리를 한 화면으로 모으고, 4.4의 지역 해금을 구현한다.



43일차에 레벨로 임시 처리한 상점 상품 해금을 지역 진행 기준으로 바꾸고, 지역 진행을 저장 항목에 넣는다.



\---



\## 2. 구현 내용



\- 지역 데이터 구조와 지역 9곳 추가

\- 지역 해금, 방문, 클리어 처리 추가

\- 월드맵 화면 추가

\- 월드맵에 성장 메뉴와 저장 버튼 이동

\- 메인 메뉴를 월드맵, 스토리, 종료와 저장 메뉴만 남도록 수정

\- 지역 선택 화면을 고른 지역의 화면으로 수정

\- 저장 데이터에 지역 진행 추가

\- 상점 상품 해금을 챕터 클리어 기준으로 수정

\- 스토리 종료 뒤 이동을 월드맵으로 수정

\- 돌아가기 동작 수정

\- 월드맵용 이미지 요청문 작성과 지역 문양 적용

\- Unity 에디터 버전 변경

지역 데이터에는 순서, 지역 문양 이름, 지역 화면 배경 이름, 지도 위 위치도 들어 있다. 지도 위 위치는 지도 그림의 왼쪽 아래를 0, 오른쪽 위를 1로 한 비율이라 지도 크기가 바뀌어도 같은 자리에 놓인다.



지역 소개 문장은 기획서에 있는 두 곳(왕국·엘프의 숲, 깊은 숲)만 넣고 나머지는 비워 두었다.

\## 4. 해금 규칙



기획서 4.4.1과 8.3을 따른다.



| 규칙 | 내용 |

| --- | --- |

| 처음 상태 | 첫 지역만 열려 있음 |

| 해금 | 앞 지역을 클리어하면 다음 지역이 열림 |

| 재방문 | 클리어한 지역은 언제든 다시 들어갈 수 있음 |

| 레벨 제한 | 없음 |



지역이 열렸는지는 따로 저장하지 않고 앞 지역의 클리어 여부에서 계산한다. 저장하는 값은 지역별 방문 여부와 클리어 여부, 마지막으로 들어간 지역이다.



월드맵에 보이는 상태는 네 가지다.



| 상태 | 조건 | 표시 |

| --- | --- | --- |

| 잠김 | 앞 지역을 클리어하지 않음 | 어두운 받침, 어두운 문양, 자물쇠 |

| 새로 해금 | 열렸지만 들어간 적 없음 | NEW 표시 |

| 진행 중 | 들어간 적 있음 | 밝은 받침 |

| 클리어 | 클리어함 | 완료 받침, 클리어 표시 |



지역을 클리어하면 다음 지역이 열리고, 월드맵에 돌아왔을 때 새로 열린 지역을 한 번 안내한다.



지역 클리어 조건은 임시다. 기획서 4.14.1의 조건은 주요 히로인 3단계 전투 승리인데 히로인전 3단계가 아직 없어, 지금은 그 지역에서 한 번 승리하면 클리어로 처리한다. 2번부터 9번 지역도 1번 지역의 시험 전투를 쓴다.

\## 5. 월드맵 화면



새 씬 10 WorldMap을 추가했다.



| 영역 | 내용 |

| --- | --- |

| 위쪽 | 화면 제목, 레벨과 보유 재화 |

| 상단 메뉴 | 덱 편성, 마물 강화, 소환사, 그리모어 강화, 상점, 저장 |

| 왼쪽 | 틀 안의 대륙 지도와 지역 표시 9개 |

| 오른쪽 | 고른 지역의 문양, 이름, 챕터, 주요 히로인, 상태, 전투 주제, 진입 버튼 |

| 아래쪽 | 안내 문구, 메인 메뉴로 돌아가기 |



대륙 지도는 지역 선택 화면의 배경으로 쓰던 그림을 그대로 쓴다. 화면 전체에 깔면 상단 메뉴와 지역 정보 창이 지도의 위쪽과 오른쪽 지역을 가리므로, 틀 안에 줄여서 놓고 그 위에 지역 표시를 얹었다.



지역 표시는 실행 중에 지역 데이터로 만든다. 받침은 그리모어 강화의 노드 받침 세 가지(잠김, 열림, 완료)를 함께 쓰고, 그 위에 지역 문양과 상태 표시를 올린다. 고른 지역은 밝은 이름판으로 표시하고, 마지막으로 들어간 지역에는 위치 표시가 붙는다.



지역의 위치는 지도 그림의 지형에 맞춰 정했다.



| 지역 | 지도의 지형 |

| --- | --- |

| 왕국·엘프의 숲 | 서쪽의 성벽 도시 |

| 사막 신전 도시 | 남쪽 사막의 요새 |

| 제국 | 가운데의 큰 성 |

| 깊은 숲 | 남쪽 가운데의 호수 숲 |

| 마법 연구시설 | 동쪽의 석조 유적 |

| 북방 설원 | 북쪽의 설산 |

| 마녀의 황무지 | 북동쪽의 바위 성 |

| 천계 성역 | 북서쪽 구름 옆의 탑 |

| 마계와 심연 | 남동쪽 바다의 바위섬 |



기획서 10.17에 따라 권장 레벨과 위험도는 표시하지 않는다.

\## 6. 화면 흐름 변경



| 화면 | 44일차까지 | 45일차 |

| --- | --- | --- |

| 메인 메뉴 | 성장 메뉴 7개와 종료, 저장 메뉴 | 월드맵, 스토리, 종료, 저장 메뉴 |

| 이어하기, 새 게임 | 메인 메뉴에 머묾 | 바로 월드맵으로 이동 |

| 월드맵 | 없음 | 지역 선택, 성장 메뉴, 저장 |

| 지역 화면 | 지역 선택이라는 이름의 스테이지 목록 | 고른 지역의 스테이지 목록 |

| 스토리 종료 뒤 | 지역 선택 | 월드맵 |

| 수동 저장 | 지역 선택에서 진입 | 월드맵에서 진입 |



지역 화면은 제목이 들어온 지역의 이름으로 바뀌고, 지역 배경 그림이 있으면 배경도 바뀐다. 지금은 1번 지역만 배경 그림이 있다. 소환사, 그리모어 강화, 상점, 저장 버튼은 월드맵으로 옮겼고 덱 편성과 소모성 아이템 장착 칸은 남겼다.



돌아가기 동작을 고쳤다. 지금까지는 바로 앞 화면으로 돌아갔는데, 덱 편성과 강화처럼 서로 오갈 수 있는 화면에서는 돌아가기가 두 화면만 왕복했다. 메인 메뉴, 월드맵, 지역 화면을 중심 화면으로 두고, 돌아가기는 들어올 때 거친 중심 화면으로 가게 했다.

\## 7. 저장과 상점 연결



저장 데이터에 지역별 방문 여부와 클리어 여부, 마지막으로 들어간 지역을 더했다. 저장 화면의 칸 상세에 현재 지역과 클리어한 지역 수가 나온다.



지역에 처음 들어갈 때 자동 저장한다. (기획서 15.6)



저장 데이터 버전은 1을 유지했다. 44일차에 만든 저장 파일에는 지역 항목이 없지만, 파일에 없는 항목은 빈 값으로 읽히므로 첫 지역만 열린 상태로 불러온다.



상점 상품 해금을 기획서 9.12.2의 챕터 클리어 기준으로 바꿨다. 43일차의 레벨 기준은 쓰지 않는다.



| 상품 | 해금 조건 |

| --- | --- |

| 마물의 정수 1개, 하급 회복 물약 | 처음부터 |

| 마물의 정수 10개, 마나 결정 | 챕터 2 클리어 |

| 욕망의 파편 1개, 보호의 인장 | 챕터 3 클리어 |

| 기억의 깃펜 | 챕터 4 클리어 |

| 정화의 향 | 챕터 5 클리어 |

\## 9. Unity 에디터 버전 변경



에디터를 6000.3.9f1에서 6000.3.21f1로 올렸다. 같은 6000.3 계열 안의 변경이다.



| 항목 | 내용 |

| --- | --- |

| 이전 버전 | 6000.3.9f1 |

| 변경 버전 | 6000.3.21f1 |

| 버전 파일 | ProjectSettings/ProjectVersion.txt |

| 패키지 목록 (manifest.json) | 변경 없음 |

| 패키지 잠금 (packages-lock.json) | 딸린 패키지 6개의 버전이 자동으로 올라감 |

| 렌더 파이프라인 전역 설정 | Unity가 새 버전 형식으로 갱신 |



버전 파일을 먼저 고친 뒤 Unity Hub에서 프로젝트를 다시 열었다. 새 버전으로 처음 열 때 에셋을 다시 읽어 들이며 약 4분이 걸렸다.



새 버전에서 스크립트 컴파일이 통과했고, 스크립트를 고칠 일은 없었다.

\## 16. 작업 결과



월드맵이 게임의 중심 화면이 되었다. 지역 선택, 성장 메뉴, 저장이 한 화면에 모였고, 메인 메뉴는 게임을 시작하고 끝내는 역할만 남았다.



지역을 클리어하면 다음 지역이 열리는 진행 구조가 생겼다. 상점 상품 해금이 이 진행에 연결되어 레벨 기준의 임시 처리가 없어졌다.



지역은 데이터 에셋이라 이름, 히로인, 전투 주제, 지도 위 위치를 코드 없이 고칠 수 있다.



지역 진행이 저장 항목에 들어가 저장 기능과 함께 이어진다. 스테이지와 히로인전 진행도는 같은 지역 항목에 더하면 된다.
