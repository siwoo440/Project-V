\# Project V 36일차 개발일지



\---



\## 1. 작업 목표



35일차에 마물별 고유 효과를 적용했지만 같은 계열을 모을 이유는 부족했다. 기획서 7.7과 7.8의 타입 시너지를 구현해 필드의 계열 구성이 전투에 영향을 주도록 한다.



\---



\## 2. 구현 내용



\- 시너지 효과 종류 열거형 추가

\- 시너지 데이터 추가

\- 시너지 단계 판정 구현

\- 필드 계열 수 집계 구현

\- 지속 보정 적용 구현

\- 마물 능력치에 시너지 보정 반영

\- 소환 시너지 처리 구현

\- 사망 시너지 처리 구현

\- 턴 시작 시너지 처리 구현

\- 턴 종료 시너지 처리 구현

\- 턴당 1회 발동 제한 구현

\- 시너지 단계 변경 로그 추가

\- 시너지 표시 UI 추가

\- 시너지 데이터 자동 연결 구현

\- 시너지 데이터 9계열 제작



\---



\## 3. 시너지 계산 규칙



기획서 7.7을 기준으로 처리한다.



\- 필드에 존재하는 마물 수를 기준으로 계산

\- 같은 이름의 마물도 각각 1체로 계산

\- 두 타입을 가진 마물은 두 타입 모두에 1체로 계산

\- 여러 타입 시너지를 동시에 활성화할 수 있음

\- 소환과 사망 직후 단계를 즉시 갱신

\- 조건을 잃으면 즉시 해제

\- 토큰 마물도 필드에 있으면 계열 수에 포함



\---



\## 4. 보정 적용 방식



시너지 보정은 상태 효과와 분리된 별도 계층으로 관리한다.



\- 최대 HP, 공격력, 방어력, 욕정 부여량 4종 보정

\- 갱신할 때마다 보정값 전체를 다시 계산해 덮어쓰기

\- 누적 방식을 사용하지 않아 단계 해제 시 원복이 보장됨

\- 최대 HP가 줄어들면 현재 HP를 함께 보정



\---



\## 5. 발동 지점



| 시점 | 처리 |

| --- | --- |

| 전투 시작 | 시너지 초기화 |

| 마물 소환 직후 | 단계 갱신 후 소환 시너지 실행 |

| 마물 사망 직후 | 단계 갱신 후 사망 시너지 실행 |

| 플레이어 턴 시작 | 턴당 1회 기록 초기화, 회복과 대기시간 감소 |

| 플레이어 턴 종료 | 대기시간 감소 |

\## 6. 적용한 시너지



| 계열 | 단계 | 효과 |

| --- | --- | --- |

| 고블린 | 4체 | 모든 고블린 ATK +3 |

| 슬라임 | 2체 | 모든 슬라임 최대 HP +5 |

| 슬라임 | 4체 | 슬라임 소환 시 보호막 5 획득 |

| 악마 | 2체 | 모든 악마 ATK +3 |

| 정령 | 2체 | 매 턴 처음 정령 소환 시 마나 1 회복 |

| 정령 | 4체 | 턴 시작 시 정령의 재사용 대기시간 추가 1 감소 |

| 기계 | 2체 | 기계 소환 시 보호막 6 획득 |

| 기계 | 4체 | 턴 종료 시 기계의 재사용 대기시간 추가 1 감소 |

| 천사 | 2체 | 턴 시작 시 플레이어 HP 2 회복 |

| 천사 | 3체 | 모든 아군 DEF +3 |

| 언데드 | 2체 | 턴마다 처음 언데드 사망 시 카드 1장 드로우 |

| 촉수 | 2체 | 촉수 기본 공격 욕정 부여량 +2 |

| 괴수 | 2체 | 모든 괴수 최대 HP +8, ATK +2 |



9계열 14단계를 제작했다. 시작 덱 구성은 고블린 8장, 슬라임 6장, 정령 6장, 악마 3장, 기계 3장이므로 고블린과 슬라임, 정령 시너지를 실제 전투에서 확인할 수 있다.



\---



\## 7. 제외한 단계



현재 전투 시스템에 없는 규칙이 필요한 단계는 제외했다.



| 필요 규칙 | 해당 단계 |

| --- | --- |

| 구속 상태 | 촉수 4체, 촉수 6체 |

| 카드 회수와 마나 비용 감소 | 슬라임 6체, 언데드 4체, 언데드 6체, 고블린 2체 |

| 소환 턴 행동 허용 | 슬라임 8체, 고블린 8체 |

| 행동 횟수 집계와 추가 공격 | 고블린 6체, 악마 3체, 악마 4체, 괴수 3체, 괴수 4체 |

| 보호막 파괴 감지 | 기계 6체 |

| 치명적 피해 생존 | 천사 4체 |



마나 비용 감소와 카드 회수는 덱 편성 기능과 함께, 구속은 상태 효과 확장과 함께 처리한다.

\## 8. 시너지 UI



기획서 7.9에 따라 전투 화면 왼쪽에 배치했다.



\- 필드에 존재하는 계열만 표시

\- 계열 이름, 현재 마물 수, 활성 단계 수 표시

\- 다음 단계까지 필요한 마물 수 표시

\- 활성 단계는 타입 색상, 비활성은 회색 표시

\- 단계 변경 시 전투 로그 기록

\## 9. 테스트 내용



\- 고블린 3체에서 단계 미활성

\- 고블린 4체에서 단계 활성과 공격력 증가

\- 고블린 사망 시 단계 해제와 능력치 원복

\- 슬라임 2체 최대 HP 증가

\- 슬라임 4체 소환 보호막 획득

\- 정령 소환 마나 회복과 턴당 1회 제한

\- 기계 턴 종료 대기시간 감소

\- 천사 3체 전체 아군 방어력 증가

\- 언데드 사망 드로우

\- 두 계열 동시 활성화

\- 토큰 마물 계열 수 포함

\- 시너지 UI 표시 갱신

\- Unity Console 오류 확인



\---



\## 10. 작업 결과



필드의 계열 구성에 따라 시너지가 즉시 활성화되고 해제된다. 같은 계열을 모으면 능력치와 자원이 늘어나므로 덱 구성이 전투 방식에 직접 영향을 준다.



지속 보정을 누적하지 않고 매번 다시 계산하는 방식으로 구현해 단계 해제 시 능력치가 정확히 원복된다.

\## 11. 다음 개발 방향



37일차에는 덱 편성 기능을 구현한다. 33일차에 만든 덱 편성 화면은 보유 카드와 현재 덱을 표시하는 읽기 전용 상태이므로 카드 추가와 제거, 편성 검증 연동, 덱 저장을 처리한다.
