\# Project V 40일차 개발일지



\---



\## 1. 작업 목표



39일차까지 플레이어 자신은 성장하지 않았다. 전투 경험치는 쌓이기만 했고, 마물 강화 상한은 Lv.5로 고정되어 있어 게임을 시작하자마자 최대 단계까지 강화할 수 있었다. 기획서 6.3의 플레이어 레벨과 부록 A.41의 경험치 공식을 구현하고, 6.3.6에 따라 플레이어 레벨이 마물 강화 상한을 정하도록 연결한다.



39일차에 임의로 정했던 마물 강화 비용을 기획서 9.11 표에 맞게 정정한다.

\## 3. 경험치 공식



기획서 부록 A.41의 공식을 그대로 사용한다.



다음 레벨 필요 경험치 = 100 + 30 × (현재 레벨 - 1)



| 항목 | 값 |

| --- | --- |

| 시작 레벨 | Lv.1 |

| 최대 레벨 | Lv.30 |

| Lv.1 → Lv.2 | 100 |

| Lv.5 → Lv.6 | 220 |

| Lv.29 → Lv.30 | 940 |

| Lv.30까지 총 경험치 | 15,080 |



레벨은 따로 저장하지 않고 누적 경험치에서 계산한다. 저장할 값이 누적 경험치 하나로 줄어들고, 경험치 곡선을 조정해도 기존 진행 데이터가 어긋나지 않는다.



기획서 6.17.1에 따라 Lv.30에 도달하면 경험치를 더 받지 않는다. 초과 경험치는 다른 재화로 바꾸지 않는다.



기획서 6.2.2에 따라 레벨이 올라도 플레이어 HP는 증가하지 않는다.

\## 4. 마물 강화 상한



기획서 6.3.6에 따라 플레이어 레벨이 마물 강화 상한을 정한다.



| 플레이어 레벨 | 마물 강화 상한 |

| --- | --- |

| Lv.1\~5 | Lv.1 |

| Lv.6\~10 | Lv.2 |

| Lv.11\~15 | Lv.3 |

| Lv.16\~20 | Lv.4 |

| Lv.21\~30 | Lv.5 |



게임을 시작한 직후에는 마물을 강화할 수 없고 Lv.6부터 강화가 열린다.



기획서 6.3.6의 표에는 Lv.15가 빠져 있다. 6.3.5의 해금 표에서 강화 Lv.3이 Lv.11, 강화 Lv.4가 Lv.16에 열리므로 Lv.15는 강화 Lv.3으로 처리했다.



상한에 막히면 "플레이어 Lv.6에 마물 Lv.2 강화가 해금됩니다"처럼 필요한 레벨을 안내한다.

\## 5. 레벨업 해금 표



기획서 6.3.5의 해금 표를 등록하고 레벨이 오를 때 해당 구간의 해금 내용을 표시한다.



| 플레이어 레벨 | 해금 |

| --- | --- |

| Lv.2 | 패시브 시스템 |

| Lv.3 | 첫 패시브 포인트 |

| Lv.5 | 신규 액티브 스킬 / 상점 상품 |

| Lv.6 | 마물 강화 Lv.2 |

| Lv.11 | 마물 강화 Lv.3 |

| Lv.16 | 마물 강화 Lv.4 |

| Lv.21 | 마물 강화 Lv.5 |

| Lv.30 | 최종 액티브·패시브 / 최종 상점 상품 |



Lv.10, 14, 20, 25의 액티브·패시브·상점 해금도 같은 표에 들어 있다.



이번 일차에 실제로 동작하는 해금은 마물 강화 상한뿐이다. 패시브, 액티브, 상점 해금은 문구만 표시되며 해당 시스템을 구현하는 일차에 연결한다.

\## 6. 마물 강화 비용 정정



39일차에는 비용을 임의로 정했다. 기획서 9.11과 부록 A.45에 정확한 표가 있어 그 값으로 교체했다.



| 강화 | 정수 | 일반 | 희귀 | 특수 | 전설 |

| --- | --- | --- | --- | --- | --- |

| Lv.1 → Lv.2 | 5 | 200 | 300 | 400 | 600 |

| Lv.2 → Lv.3 | 10 | 500 | 750 | 1,000 | 1,500 |

| Lv.3 → Lv.4 | 20 | 1,000 | 1,500 | 2,000 | 3,000 |

| Lv.4 → Lv.5 | 40 | 2,000 | 3,000 | 4,000 | 6,000 |

| 합계 | 75 | 3,700 | 5,550 | 7,400 | 11,100 |



정수 비용은 희귀도와 관계없이 같고 골드 비용만 희귀도에 따라 다르다. 39일차 일지 4절의 비용 표는 이 표로 대체한다.

\## 7. 레벨 표시



| 위치 | 표시 |

| --- | --- |

| 전투 결과 화면 | 레벨 변화와 해금 내용 |

| 전투 화면 하단 | 레벨과 경험치 |

| 메인 메뉴 | 레벨과 경험치 |

| 마물 도감 요약 | 레벨과 경험치 |

| 강화 화면 | 플레이어 레벨, 강화 상한, 다음 해금 레벨 |



레벨과 경험치는 "Lv.5 (140 / 220)" 형식으로 표시하고 최대 레벨에서는 "Lv.30 (최대)"로 표시한다.



전투 결과 화면은 계속 버튼을 누르면 보상 수령과 동시에 닫힌다. 수령한 뒤에 레벨 변화를 보여주면 볼 수 없으므로, 버튼을 누르기 전에 예상 레벨 변화를 미리 계산해 표시한다.



최대 레벨에서는 받을 경험치가 0으로 표시된다.

\- Lv.2 사본의 다음 강화가 Lv.11 해금으로 차단

\- 패배 시 경험치 미지급

\## 14. 작업 결과



전투에서 얻은 경험치가 플레이어 레벨로 이어지고, 레벨이 마물 강화 상한을 열어 준다. 전투, 경험치, 레벨, 강화, 더 어려운 전투로 이어지는 성장 흐름이 처음으로 연결되었다.



강화 비용이 기획서 수치와 같아져 정수와 골드의 가치를 기획서의 보상 수치와 같은 기준으로 맞출 수 있게 되었다.



누적 경험치는 저장 대상이다. 게임을 종료하면 초기화되며 저장은 저장 및 불러오기 일차에서 처리한다.
