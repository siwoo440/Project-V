\# Project V 32일차 개발일지



\---



\## 1. 작업 목표



기획서 7.2의 마물 타입 9종을 데이터로 추가하고, 기획서 6.8.2의 시작 덱 마물 11종과 카드 11종을 제작한다. 31일차에 구현한 보유 한도 및 덱 검증 위에서 전투 덱을 30장으로 복귀하는 것을 목표로 한다.



\---



\## 2. 구현 내용



\- 마물 타입 열거형 추가

\- 마물 타입 표시 이름 규칙 추가

\- 마물 데이터에 주 타입 추가

\- 마물 데이터에 보조 타입 추가

\- 마물 데이터에 보스 출신 여부 추가

\- 카드 데이터에 타입 조회 추가

\- 카드 데이터에 보스 출신 조회 추가

\- 덱 전설 편성 제한 검증 구현

\- 덱 보스 출신 편성 제한 검증 구현

\- 시작 덱 마물 11종 제작

\- 시작 덱 카드 11종 제작

\- 기존 테스트 마물 6종 타입 지정

\- 시작 보유 카드 목록 30장 구성

\- 전투 덱 30장 구성

\- 시작 손패 및 드로우 규칙 반영

\## 3. 마물 타입 구성



기획서 7.2의 최종 타입 9종을 사용한다.



\- 촉수

\- 슬라임

\- 고블린

\- 악마

\- 언데드

\- 괴수

\- 정령

\- 기계

\- 천사



혼종, 야수, 특수, 보스는 타입으로 사용하지 않는다. 특수는 희귀도로만 사용하고, 보스 출신 여부는 편성 제한 판정을 위해 내부 데이터로만 저장한다. 보조 타입은 일부 마물만 보유하며 양쪽 시너지에 각각 1체로 계산한다.

\## 4. 덱 편성 제한



기획서 7.5의 추가 편성 제한을 검증에 반영했다.



| 항목 | 제한 |

| --- | --- |

| 전설 마물 | 덱 전체 최대 3장 |

| 같은 전설 마물 | 1장 |

| 보스 출신 마물 | 덱 전체 최대 1장 |



보스 출신 마물도 전설 3장 제한에 포함된다. 같은 전설 마물 1장 제한은 31일차의 희귀도별 중복 제한으로 이미 처리된다.

\## 7. ID 체계



신규 마물과 카드는 기획서 부록 B의 ID 체계를 사용한다.



\- 마물: MON-계열-번호

\- 카드: CRD-계열-번호



기존 테스트 마물 6종은 M001 체계를 유지하고 삭제하지 않았다. 씬의 포획 보상과 전투 참조가 연결되어 있어 삭제하면 31일차에 검증한 흐름을 다시 구성해야 하기 때문이다. 기존 6종에는 타입만 지정해 시너지 계산에 사용할 수 있도록 했다.

\## 9. 작업 결과



마물 타입 데이터를 추가하고 기획서 기준 시작 덱 30장을 구성했다. 31일차의 보유 한도 검증이 신규 데이터에서 정상 동작하며, 전설과 보스 출신 편성 제한도 검증에 포함됐다.



마물 고유 효과는 이번 일차에서 구현하지 않았다. 소환 시 드로우, 사망 시 소환, 보호막 복사 등은 효과 시스템이 필요하므로 33일차에 처리한다. 레벨 성장 수치는 역할에 따라 임시로 지정했으며, 기획서 6.9.4의 강화 단계별 효과는 37일차 마물 카드 강화에서 정식 적용한다.



기획서 6.9.3은 강화 재료로 골드와 공용 강화 재료를 사용한다고 명시하지만 9.11은 마물의 정수와 골드를 사용한다. 31일차에 9.11 기준으로 구현했으므로 6.9.3을 정리할 필요가 있다.
