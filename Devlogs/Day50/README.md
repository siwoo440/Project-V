\## 1. 작업 목표



49일차까지는 지역 화면에서 스테이지를 고르고 전투 시작을 누르면 바로 전투가 시작됐다. 상대 정보는 상세 칸에 글자로만 나왔고, 소환사 스킬이나 패시브를 바꾸려면 월드맵까지 돌아가야 했다.



기획서 6.14와 10.18의 전투 준비 화면을 만들어 전투 직전에 상대와 내 준비 상태를 한 화면에서 확인하고 바꾸게 한다. 전투 안에는 전투 속도, 전투 포기, 패배 뒤 재도전을 넣는다. (기획서 10.19 / 10.22 / 10.23.1 / 11.11)



\---



\## 2. 구현 내용



\- 전투 준비 화면(11\_BattlePrepare 씬) 추가

\- 상대 안내 추가: 히로인의 능력치와 행동별 효과, 적 마물별 능력치

\- 내 준비 상태 표시와 덱 프리셋, 액티브 스킬, 패시브, 소모품 변경 추가

\- 난이도 선택과 보상 안내를 전투 준비 화면으로 이동

\- 지역 화면의 난이도 버튼과 소모품 칸 삭제

\- 덱 장수가 맞지 않으면 전투를 시작할 수 없도록 추가

\- 전투 속도(1배, 1.5배, 2배) 추가

\- 전투 포기 추가

\- 패배 결과 창의 재도전 추가

\- 씬 파일이 없으면 씬 구성 도구가 만들고 빌드 목록에 넣도록 추가

\## 3. 전투 준비 화면



지역 화면의 전투 준비 버튼을 누르면 이 화면을 거쳐 전투가 시작된다.



| 구역 | 내용 |

| --- | --- |

| 위 | 화면 제목, 지역과 스테이지 이름, 전투 종류 |

| 왼쪽: 상대 | 이름, 능력치, 행동. 히로인은 그림을 함께 보여 준다 |

| 오른쪽: 내 준비 | 플레이어 레벨, 덱 프리셋, 덱 요약, 액티브 스킬, 패시브, 소모품 |

| 왼쪽 아래 | 난이도 버튼, 받을 보상, 승리 기록, 최초 보상 상자 |

| 오른쪽 아래 | 안내 줄, 지역으로, 전투 시작 |



지역 화면이 정해 둔 전투(BattleSetup)를 읽어 보여 준다. 전투를 정하지 않고 들어오면 안내만 보이고 전투 시작이 잠긴다.

\## 4. 상대 안내



기획서 10.18의 전투 전 정보다. 추천 덱, 추천 계열, 추천 시너지는 적지 않는다.



| 상대 | 보여 주는 것 |

| --- | --- |

| 히로인 | 고른 난이도의 HP, 공격, 방어, 성욕 저항, 한 턴의 행동 횟수, 행동마다 대상과 피해, 보호막, 재사용 대기, 페이즈 전환 조건 |

| 적 마물 | 마물마다 계열, 희귀도, 고른 난이도의 HP, 공격, 방어, 공격에 딸린 상태 효과 |

| 시험 히로인 | 난이도와 승리 기록이 없다는 안내 |



히로인 행동의 피해는 공격력에 행동 배율을 곱한 실제 값으로 적는다. 아리아 1차전 보통 난이도라면 기사의 참격은 피해 8, 방패 전진은 피해 6과 보호막 18이다.



적 마물의 능력치 계산을 한곳(EnemyBattleRules)으로 모아, 전투의 마물 판과 준비 화면이 같은 계산을 쓴다.

덱이 필요한 장수(30장)와 다르면 전투 시작이 잠기고 이유를 안내 줄에 적는다.

\## 6. 난이도와 보상



난이도 버튼은 난이도를 고를 수 있는 전투(일반전, 히로인전)에서만 보인다. 포획전은 지역마다 고정이라 보이지 않는다.



난이도를 바꾸면 상대 능력치와 보상을 바로 다시 적는다. 마지막으로 고른 난이도를 기억해 다음 전투를 정할 때도 그 난이도로 시작한다.



| 전투 | 보상 안내 |

| --- | --- |

| 일반전 | 골드, 경험치, 정수 |

| 포획전 | 경험치, 정수, 골드 없음, 이기면 쓰러뜨린 마물을 모두 얻는다는 안내 |

| 히로인전 | 골드, 경험치, 욕망의 파편. 3차전은 지역 클리어 보상 |



최초 승리와 반복 승리를 구분해 적고, 난이도별 승리 기록과 패배 경험치 비율을 함께 적는다. 그리모어 강화로 늘어나는 양은 넣지 않은 기본 값이다.

\## 7. 지역 화면 정리



47일차와 43일차에 임시로 지역 화면에 두었던 난이도 버튼 3개와 소모품 칸을 뺐다. 버튼 이름을 전투 준비로 바꾸고 상세 글 칸을 넓혔다.



지역 화면의 상세 글은 마지막으로 고른 난이도 기준으로 보여 준다. 포획 목록 다시 뽑기 버튼은 소모품 칸이 있던 자리로 내렸다.

\## 8. 전투 속도



전투 화면 오른쪽 위의 버튼으로 1배, 1.5배, 2배를 차례로 바꾼다. (기획서 10.22 / 11.11)



| 적용하는 것 | 적용하지 않는 것 |

| --- | --- |

| 히로인과 적 마물의 행동 사이 대기 | 피해량, 행동 순서, 행동 선택 |

| 피격 그림을 보여 주는 시간 | 플레이어의 입력 |



게임 전체의 시간 흐름을 바꾸지 않고 대기 시간만 배속으로 나눈다. 고른 속도는 기기에 저장해 다음 전투에도 쓴다.

\## 16. 다음 실행에서 확인할 내용



\- 지역 화면에서 전투 준비를 누르면 준비 화면이 열리고 고른 전투의 상대가 나오는지

\- 난이도를 바꾸면 상대 능력치와 보상이 바뀌는지

\- 프리셋 화살표, 스킬, 패시브, 소모품 버튼이 내용을 바꾸는지

\- 덱 편성과 소환사 화면에서 돌아가기를 누르면 준비 화면으로 돌아오는지

\- 덱이 30장이 아닐 때 전투 시작이 잠기는지

\- 전투 속도 버튼이 x1, x1.5, x2로 바뀌고 상대의 행동이 빨라지는지

\- 포기 버튼을 두 번 누르면 보상 없이 지역 화면으로 돌아가는지

\- 패배 결과 창에서 재도전을 누르면 같은 전투가 다시 시작되는지

\- 준비 화면의 글이 칸을 넘치지 않는지 (아리아 3차전은 행동이 6개다)

\- 49일차에서 넘어온 항목: 히로인전의 승패와 보상, 해금 순서, 지역 클리어, 절정 상태, 기사단장의 각오, 여러 번 행동, 반격, 히로인 그림 반응

\- 48일차에서 넘어온 항목: 포획전, 다시 뽑기, 전투 로그와 그림 버튼

\- 47일차에서 넘어온 항목: 난이도별 적 능력치와 보상, 최초·반복 보상, 패배 경험치

\- 46일차에서 넘어온 항목: 적 마물 배치, 공격 대상 선택, 적 턴, 적 전멸 승리

\- 44일차에서 넘어온 항목: 이어하기, 불러오기, 수동 저장, 삭제

\- 43일차에서 넘어온 항목: 상점 구매 결과, 전투에서의 소모성 아이템 사용

\- 42일차에서 넘어온 항목: 그리모어 전투 효과, 소환사 화면과 스킬 사용, 마물 판의 상태 효과 아이콘



전투를 끝까지 진행한 실행 기록이 46일차부터 한 번도 없다. 52일차 점검 전에 지역 1의 전투를 한 번이라도 끝까지 해 보는 것이 필요하다.

\## 17. 작업 결과



전투에 들어가기 전에 준비하는 단계가 생겼다. 상대가 무엇을 하는지 보고, 그에 맞춰 덱과 스킬, 패시브, 소모품, 난이도를 한 화면에서 정한다. 지역 화면은 어떤 전투를 할지 고르는 일만 맡는다.



전투 안에서는 속도를 올려 상대의 행동을 빨리 넘기고, 이길 수 없는 전투는 포기하고, 진 전투는 바로 다시 할 수 있다.
