\## 3. 효과 데이터 구조



| 항목 | 내용 |

| --- | --- |

| 발동 시점 | 소환, 지속, 능동 스킬, 사망 |

| 효과 종류 | 드로우, 마나 회복, 보호막 획득, 보호막 복사, 아군 공격력 증가, 아군 회복, 디버프 제거, 성욕 부여, 플레이어 회복, 토큰 소환 |

| 수치 | 기본 수치, 추가 수치, 상한, 플레이어 HP 소비 |

| 조건 | 대상 계열, 다른 아군 필요 여부, 아군 수 비례 여부 |

| 참조 | 부여할 상태 효과, 소환할 토큰 마물 |



효과는 마물 데이터에 목록으로 연결하며 한 마물이 여러 효과를 가질 수 있다. 아군 수에 비례하는 수치는 상한을 함께 지정한다.



\---



\## 4. 발동 지점



| 시점 | 처리 |

| --- | --- |

| 소환 직후 | 소환 효과 실행 |

| 스킬 사용 | 스킬 효과 실행 후 대기시간 적용 및 행동 완료 |

| 사망 | 필드에서 제거한 뒤 사망 효과 실행 |

| 플레이어 턴 종료 | 모든 마물의 재사용 대기시간 감소 |



사망 효과는 자리를 먼저 비운 뒤 실행한다. 기획서의 빈 필드 조건을 만족시키기 위해서다.

\## 6. 토큰 마물



점액 잔재를 토큰 마물로 제작했다.



\- HP 6, 공격 3, 욕정 2, 방어 0

\- 필드에만 존재하며 덱에 편성할 수 없음

\- 포획과 보유 대상에서 제외

\- 필드가 가득 차면 소환되지 않음



덱 검증에 토큰 마물 편성 차단 항목을 추가했다.



\---



\## 7. 사망 처리 통합



마물 사망 처리가 단일 공격, 광역 공격, 독 피해 세 곳에 나뉘어 있었다. 사망 효과를 한 곳에서만 실행하기 위해 사망 처리 함수 하나로 통합했다.



통합한 처리 내용은 다음과 같다.



\- 선택 상태 해제

\- 히로인 예고 대상 해제

\- 필드 목록에서 제거

\- 사망 효과 실행

\- 오브젝트 제거



\---



\## 8. 한글 글꼴 도구 보완



동적 글꼴이 새 글자를 아틀라스에 추가할 때마다 임포터 경고가 발생했다. 프로젝트에서 사용하는 한글 글자를 한 번에 아틀라스에 넣는 기능을 추가했다.



\- 프로젝트 파일에서 사용 중인 한글 글자 수집

\- 글꼴 아틀라스에 일괄 추가

\- 표본 크기를 90에서 48로 축소

\- 프로젝트에 글꼴 파일이 있으면 시스템 글꼴보다 우선 사용



현재 프로젝트에서 사용하는 한글은 404자다. 배포용으로는 라이선스가 자유로운 글꼴 파일을 프로젝트에 포함해야 한다.

\## 10. 작업 결과



마물의 고유 효과를 데이터로 정의하고 전투에 적용했다. 같은 계열을 모으면 드로우와 보호막이 늘어나는 등 덱 구성이 전투 방식에 영향을 준다.



흡착 슬라임의 구속과 망령 메이드의 손패 귀환은 기획서에 규칙이 정의되지 않아 제외했다. 흡착 슬라임은 욕정 부여만 적용했다. 지속 효과는 데이터 구조만 정의하고 실제 적용은 시너지와 함께 처리한다.



스킬 버튼과 마물 카드의 스킬 표시는 씬 UI 도구 실행 시 생성된다. 도구를 실행해야 전투에서 스킬을 사용할 수 있다.
