\# Project V 53일차 개발일지



\---



\## 1. 작업 목표



스토리 시스템을 넣는다. 지금까지의 스토리 화면은 씬에 적힌 대사를 차례로 보여 주는 시험용이었다. 대사를 데이터로 옮기고, 인물 그림과 진행 기능을 넣고, 지역 진행의 정해진 지점에 연결한다. (기획서 10.21 / 12.12 / F.3.1)



49일차에 임시로 둔 두 가지도 정식으로 바꾼다. 아리아 1차전은 지역에 들어가기만 하면 열렸고, 지역 클리어 보상은 3차전을 이기는 순간 바로 들어왔다.



\---



\## 2. 구현 내용



\- 스토리 장면 데이터 형식 추가

\- 스토리 화면에 배경과 인물 자리 3개, 화자 강조 추가

\- 건너뛰기 확인 창, 자동 진행, 빠른 진행 추가

\- 본 장면 기록과 저장 추가

\- 지역 도입 스토리와 마무리 스토리를 지역 진행에 연결

\- 아리아 1차전의 해금 조건을 도입 스토리 완료로 수정

\- 지역 클리어와 보상 시점을 마무리 스토리 완료로 수정

\- 지역 1의 시험 장면 2개 추가

\- 대화용 그림 이름 규칙과 도윤, 그리모어 그림 요청문 추가

\- 52일차 점검 순서표를 새 진행 순서에 맞게 수정

\## 3. 스토리 데이터



장면 하나가 데이터 파일 하나다. 장면에는 고유 이름, 제목, 줄의 목록이 있다.



| 줄의 항목 | 내용 |

| --- | --- |

| 화자 이름 | 대화창의 이름 칸에 표시 |

| 대사 | 대화창에 표시 |

| 화자 자리 | 없음, 왼쪽, 가운데, 오른쪽. 이 자리의 인물을 강조 |

| 왼쪽, 가운데, 오른쪽 그림 | 각 자리에 설 인물 |

| 배경 | 바꾸는 줄에만 적음 |



그림 칸은 인물이 바뀌는 줄에만 적는다.



| 적는 값 | 뜻 |

| --- | --- |

| 비움 | 앞 줄의 상태를 유지 |

| - | 그 자리를 비움 |

| Aria | 아리아의 기본 그림 |

| Aria:Shaken | 아리아의 지정한 표정 그림 |

\## 4. 스토리 화면



배경 위에 인물이 왼쪽, 가운데, 오른쪽 세 자리에 서고 아래에 대화창이 있다. 인물 자리는 520×780 크기이고 대화창 뒤에 놓인다. 예전에 가운데에 하나만 두었던 빈 인물 자리는 지웠다.



| 줄의 종류 | 인물 표시 |

| --- | --- |

| 화자 자리가 있는 줄 | 말하는 인물은 원래 밝기에 1.05배 크기, 나머지는 어둡게 |

| 화자 자리가 없는 줄 (해설) | 모두 원래 밝기 |



인물 그림은 대화용 그림을 먼저 찾고, 없으면 전투 그림을 대신 쓴다.



| 찾는 순서 | 파일 |

| --- | --- |

| 지정한 표정의 대화용 그림 | <이름>\_Talk\_<표정>\_01 |

| 기본 표정의 대화용 그림 | <이름>\_Talk\_Normal\_01 |

| 전투 그림 | <이름>\_Battle\_<상태>\_01 |



아리아는 49일차에 받은 전투 그림이 있어 대화용 그림 없이도 화면에 선다.

\## 5. 진행 기능



| 기능 | 동작 |

| --- | --- |

| 다음 | 다음 줄로. 마지막 줄에서는 장면을 끝냄 |

| 건너뛰기 | 확인 창을 띄우고, 건너뛰기를 고르면 장면을 끝냄. 처음 보는 장면도 건너뛸 수 있음 |

| 자동 | 켜면 대사가 저절로 넘어감. 대기 시간은 1.6초에 글자당 0.06초를 더함 |

| 빠른 진행 | Ctrl을 누르고 있는 동안 0.08초 간격으로 넘어감 |



확인 창이 떠 있는 동안에는 자동 진행과 빠른 진행이 멈춘다. 건너뛴 장면도 본 것으로 기록한다.

\## 6. 지역 진행과 연결



지역 데이터에 도입 스토리와 마무리 스토리 칸을 넣었다. 지역 화면에 들어올 때 봐야 할 장면이 있으면 그 장면을 먼저 재생한다.



| 지점 | 49일차의 임시 처리 | 수정 뒤 |

| --- | --- | --- |

| 지역에 처음 들어갈 때 | 바로 지역 화면 | 도입 스토리를 재생하고 지역 화면으로 돌아옴 |

| 아리아 1차전 해금 | 지역에 들어가면 열림 | 도입 스토리를 봐야 열림 |

| 3차전 승리 | 결과 창에서 지역 클리어와 보상 | 결과 창에는 전투 보상만 표시 |

| 3차전 뒤 지역 화면으로 돌아올 때 | 없음 | 마무리 스토리를 재생하고 월드맵으로 이동 |

| 지역 클리어와 보상 | 3차전 승리 순간 | 마무리 스토리를 끝낸 순간 |

| 클리어 안내 | 전투 결과 창 | 월드맵의 안내 줄 (지역 클리어, 골드 +500, 욕망의 파편 +30) |



스토리 칸이 빈 지역은 예전 방식 그대로 진행한다. 도입 스토리가 없으면 1차전이 처음부터 열려 있고, 마무리 스토리가 없으면 3차전 승리 때 지역이 클리어된다. 지역 2부터 9까지가 지금 이 상태다.

\## 11. 작업 결과



지역 1의 진행이 기획서의 순서(도입 스토리, 1차전, 일반전, 2차전, 부가 콘텐츠와 3차전, 마무리 스토리, 지역 클리어)와 같아졌다. 49일차의 임시 처리 두 가지가 없어졌다.



스토리를 늘리는 일은 데이터 파일을 추가하고 지역 데이터에 연결하는 것으로 끝난다. 코드를 고치지 않는다.



52일차의 실행 점검은 이번에도 하지 못했다. 전투를 끝까지 진행한 실행 기록은 46일차부터 없다.

\## 12. 다음 개발 방향



54일차에 스토리 시스템을 마무리한다.



선택지를 넣는다. 선택지는 도윤의 대사와 상대의 반응만 바꾸고 진행, 보상, 해금에는 영향을 주지 않는다. 고른 뒤에는 같은 줄기로 돌아온다. (기획서 2.10)



스토리 회상을 넣는다. 본 장면의 목록에서 장면을 골라 다시 본다. 메인 메뉴의 스토리 버튼이 이 화면으로 이어진다. (기획서 4.16.4)



히로인전의 앞뒤에 장면을 연결한다. 전투 전 대화, 승리 뒤 대화, 서브 히로인의 미니 스토리가 들어갈 자리다.



실행 점검에서 나온 문제는 보고받는 대로 먼저 고친다.
