\# Project V 48일차 개발일지



\---



\## 1. 작업 목표



47일차까지는 새 마물 카드를 얻는 정식 방법이 없었다. 시험 전투에서 이기면 확률로 마물 한 마리를 얻는 임시 처리만 있었다. 기획서 8.12와 9.13의 포획 콘텐츠를 구현해, 포획 목록에서 마물을 골라 싸우고 쓰러뜨린 마물을 카드로 얻게 한다.



전투에 들어갔을 때 전투 로그가 닫혀 있도록 하고, 전투 화면의 보조 버튼을 글자 대신 그림 버튼으로 바꾼다.



\---



\## 2. 구현 내용



\- 지역 출현 마물 목록 추가

\- 포획 목록 생성 규칙 추가

\- 포획 목록 다시 뽑기 추가

\- 전설 마물 확정 보정 추가

\- 포획전과 포획 결과 처리 추가

\- 포획전 보상 추가

\- 포획 목록 자동 갱신 추가

\- 포획 목록과 보정 횟수의 저장 추가

\- 지역 화면에 포획 목록과 다시 뽑기 버튼 추가

\- 전투 종류를 전투 씬에 넘기는 처리 재구성

\- 확률 포획 제거

\- 일반전 정수 보상 추가

\- 전투 로그가 닫힌 채로 시작하도록 수정

\- 전투 화면 보조 버튼을 그림 버튼으로 수정

\- 저장 화면 배경 적용

기획서 9.13.1의 규칙이다.



| 항목 | 내용 |

| --- | --- |

| 포획하는 곳 | 포획전에서만. 일반전에서는 포획되지 않음 |

| 포획 대상 | 포획전에서 쓰러뜨린 모든 적 마물 |

| 확률 판정 | 없음 |

| 패배 | 포획 결과가 전부 취소됨 |

포획전은 46일차의 적 마물 전투를 그대로 쓴다. 적 전멸이 승리 조건이므로 승리하면 그 목록의 마물을 모두 얻는다.

\## 4. 포획 목록

\## 6. 포획 결과와 보상



포획전에서 승리하면 결과를 받을 때 다음 순서로 처리한다. (기획서 9.14)



| 순서 | 처리 |

| --- | --- |

| 1 | 쓰러뜨린 마물마다 보유 수량 확인 |

| 2 | 보유 한도 안이면 카드 획득 |

| 3 | 보유 한도를 넘으면 마물의 정수로 변환 |

| 4 | 포획전 기본 정수와 경험치 지급 |

| 5 | 스테이지 승리 기록 |

| 6 | 포획 목록 3개 갱신 |

| 7 | 자동 저장 |



결과 화면에는 마물마다 카드를 얻는지 정수로 바뀌는지를 받기 전에 미리 보여 준다. 같은 마물이 한 목록에 여러 체 있으면 앞에서 얻은 수량까지 세어 판정한다.



보상은 기획서 9.7.4, 9.8.2, 9.10.3을 따른다.



| 보상 | 최초 승리 | 반복 승리 |

| --- | --- | --- |

| 골드 | 없음 | 없음 |

| 경험치 | 60 | 36 |

| 마물의 정수 | 3 + 쓰러뜨린 마물 수 | 최초의 60% |



경험치에는 지역 배율을 적용한다. 난이도가 고정이라 난이도 배율은 없다. 패배하면 승리 경험치의 25%만 받는다.



최초 승리는 포획 목록 번호마다 따로 센다. 지역 1의 첫째 목록은 R01-CAP1이다.



47일차에 빠뜨린 일반전의 정수 보상을 넣었다. 기획서 9.10.2에 따라 일반전 1, 2, 3단계는 최초 승리에 정수 5, 8, 12를, 반복 승리에 3, 4, 7을 준다. 지역 배율과 난이도 배율을 적용한다.

\## 7. 지역 화면



지역 화면의 스테이지 목록에 포획전 1, 2, 3이 생겼다.



| 상태 | 표시 |

| --- | --- |

| 잠김 | 자물쇠와 해금 조건 |

| 열림 | 그 목록에 나오는 마물 이름 |



포획전을 고르면 상세에 다음 내용이 나온다.



| 항목 | 내용 |

| --- | --- |

| 마물 | 이름, 계열, 희귀도 |

| 보유 | 미포획 또는 보유 수량과 한도 |

| 보상 | 최초·반복 여부, 경험치, 정수, 골드 없음 |

| 안내 | 승리와 패배의 결과, 전투 뒤 목록 갱신 |

| 보정 | 전설 마물 확정까지 남은 다시 뽑기 횟수 |



다시 뽑기 버튼은 포획전을 골랐을 때만 보이고, 난이도 버튼이 있던 줄을 쓴다. 골드가 모자라면 눌리지 않는다. 다시 뽑은 뒤에는 같은 번호의 목록이 다시 선택된다.



스테이지 줄이 일곱 개가 되어 줄 높이를 76에서 68로 줄였다.



지역 1에 있던 포획전 시험 항목은 포획 목록으로 대체했다.

\## 8. 전투 설정 재구성



46일차에는 지역 화면이 적 편성 에셋 하나를 전투 씬에 넘겼다. 포획전의 적은 에셋이 아니라 실행 중에 뽑은 목록이므로, 넘기는 내용을 전투 종류와 적 마물 목록으로 바꿨다.



| 전투 종류 | 적 | 승리 기록 ID | 난이도 |

| --- | --- | --- | --- |

| 히로인 전투 | 없음 (히로인) | 없음 | 없음 |

| 일반전 | 적 편성 에셋의 마물 | R01-G1 형식 | 고른 난이도 |

| 포획전 | 포획 목록의 마물 | R01-CAP1 형식 | 고정 |



전투 씬은 전투 종류에 따라 보상 계산을 세 갈래로 나눈다.

\## 9. 확률 포획 제거



예전 시험 전투는 승리하면 보상 데이터의 포획 확률로 마물 한 마리를 얻었다. 기획서 9.13.1은 포획 확률 판정을 쓰지 않는다고 하므로 이 처리를 없앴다. 히로인 전투에서는 포획이 일어나지 않는다.



그리모어의 포획술 노드는 포획 확률을 올리는 효과였다. 확률 포획이 없어져 지금은 효과가 없다. 노드 효과를 다시 정해야 한다.

\## 10. 전투 로그와 그림 버튼



전투에 들어가면 전투 로그가 닫힌 채로 시작한다. 닫혀 있는 동안에도 기록은 쌓이고, 로그 버튼을 누르면 처음부터 볼 수 있다.



전투 로그 패널을 씬에서 꺼 둔 채로 저장하지는 않았다. 꺼 둔 오브젝트는 처음 켜질 때 초기화가 실행되는데, 전투 로그의 초기화는 기록을 지우므로 처음 열 때 그때까지의 기록이 사라진다. 패널은 켜 둔 채로 두고 실행이 시작될 때 스스로 닫게 했다.



전투 화면의 보조 버튼을 글자 없는 둥근 그림 버튼으로 바꿔 왼쪽 아래에 세로로 놓았다.



| 버튼 | 그림 |

| --- | --- |

| 소모품 | 장착한 아이템의 그림. 없으면 빈 칸 그림 |

| 전투 로그 | 두루마리 |

| 도감 | 책 |

| 지역으로 | 지도 |

| 전투 로그 닫기, 도감 닫기 | X 표시 |



소모품 버튼의 그림은 실행 중에 장착한 아이템에 맞게 바뀌고, 이미 썼거나 쓸 수 없으면 흐려진다.



새 그림은 받지 않았다. 받침은 그리모어 강화의 둥근 노드 그림을, 아이콘은 이미 있는 것을 썼다. 아이콘 그림이 없는 환경에서는 글자 버튼이 그대로 남는다.



공격, 성욕 공격, 스킬, 턴 종료는 글자 버튼으로 두었다.

\## 16. 다음 실행에서 확인할 내용



실행 기록에서 전투 씬은 열렸지만 전투를 끝낸 기록이 없다. 전투의 진행과 결과, 포획은 아직 실행으로 확인하지 못했다. 마지막 씬 구성 뒤에는 실행하지 않았다.



\- 포획전 세 줄이 잠겨 보이다가 일반전 2단계를 이기면 열리는지

\- 다시 뽑기로 골드가 줄고 세 줄의 마물이 바뀌는지

\- 포획전에서 이기면 결과 화면에 포획한 마물이 나오고 덱 편성에 카드가 생기는지

\- 보유 한도를 넘는 마물이 정수로 바뀌는지

\- 포획전 뒤에 세 줄이 새 목록으로 바뀌는지

\- 저장 파일에 포획 목록이 들어가고 불러오면 같은 목록이 나오는지

\- 전투 로그가 닫힌 채로 시작하는지

\- 왼쪽 아래의 그림 버튼 네 개가 겹치지 않고 눌리는지

\- 저장 화면에 새 배경이 보이는지

\- 47일차에서 넘어온 항목: 일반전 순차 해금, 난이도별 적 능력치와 보상, 최초·반복 보상, 패배 경험치

\- 46일차에서 넘어온 항목: 적 마물 배치, 공격 대상 선택, 적 턴, 적 전멸 승리

\- 44일차에서 넘어온 항목: 이어하기, 불러오기, 수동 저장, 삭제

\- 43일차에서 넘어온 항목: 상점 구매 결과, 전투에서의 소모성 아이템 사용

\- 42일차에서 넘어온 항목: 그리모어 전투 효과, 소환사 화면과 스킬 사용, 마물 판의 상태 효과 아이콘

\## 17. 작업 결과



마물 카드를 얻는 정식 경로가 생겼다. 포획 목록에서 원하는 마물을 고르고, 없으면 골드로 다시 뽑고, 포획전에서 이겨 카드를 얻는다. 골드의 사용처가 마물 강화, 상점, 다시 뽑기의 세 가지가 되었다.



일반전으로 골드와 경험치를 모으고, 포획전으로 카드와 정수를 얻고, 그것으로 덱을 바꾸고 마물을 강화하는 성장 고리가 지역 1 안에서 이어진다.



전투 씬에 넘기는 내용이 전투 종류와 적 마물 목록으로 정리되어, 히로인전과 서브 히로인전을 더할 때 전투 종류만 늘리면 된다.
